# 型道場

将棋の囲い(守り)と戦法(攻め)の「型」を、自分で駒を動かして覚える個人用の学習アプリ。

**https://5uda18ma46-hub.github.io/katadojo/**

## できること

- 囲い: 美濃囲い・高美濃囲い・銀冠・舟囲い・金矢倉。順番は自由で、駒が通り道をふさぐ手だけ理由つきで止める
- 戦法: 棒銀・四間飛車・中飛車。相手は自動で指し、応じ方によって変化が分かれる
- ヒント、1手戻す、お手本(手順の再生)、変化ごとのクリア記録

## つくり

- 素のJS(ビルド不要・外部ライブラリなし)。型のデータは `lessons.js`
- 記録は端末の localStorage に保存する。サーバーには何も送らない
